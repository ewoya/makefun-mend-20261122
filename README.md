# mend

A Node 22 command-line tool that applies AI edits in unified diff, SEARCH/REPLACE, V4A and JSON formats. Built for [this make.fun bounty](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).

Run: `node main.ts [--format=NAME] [--check] [--strict] [PATCH]`.
